# 📖 용어·개념 정리 (까먹을 때 여는 치트시트)

> 프로젝트: TCP/IP 평문 채팅 + MITM 공격 시뮬레이션 + TLS 방어

---

## 1. 네트워크 기본
- **IP 주소**: 네트워크상의 "집 주소" (예: 127.0.0.1 = 내 컴퓨터).
- **포트(port)**: 한 컴퓨터 안의 "몇 호실" (우리 채팅은 9999번).
- **localhost / 127.0.0.1**: "나 자신"을 가리키는 특수 주소. 통신이 PC 밖으로 안 나감.
- **패킷(packet)**: 네트워크로 보낼 때 데이터를 잘게 쪼갠 한 덩어리.
- **MAC 주소**: 랜카드마다 붙은 고유 하드웨어 번호 (랜 안에서 기기 식별용).
- **OSI 계층**: 네트워크 통신을 7개 층으로 나눈 표준 모델 (물리~응용).

## 2. 소켓·통신
- **소켓(socket)**: 두 프로그램이 네트워크로 데이터를 주고받는 "통신 콘센트".
- **TCP**: 순서 보장 + 빠짐없이 전달하는 연결형 통신 규약.
- **UDP**: 연결 없이 빠르게 보내는 비연결형 규약 (순서·도착 보장 안 함).
- **서버(server)**: 접속을 기다렸다 받아주는 역할 (전화 받는 쪽).
- **클라이언트(client)**: 먼저 접속을 거는 역할 (전화 거는 쪽).
- **3-way handshake**: TCP 연결 시작 시 "연결할래?→그래→오케이" 3번 주고받는 과정.
- **broadcast(브로드캐스트)**: 한 명이 보낸 메시지를 접속한 모두에게 뿌리는 것 (단톡방).
- **스레드(thread)**: 한 프로그램 안에서 여러 일을 동시에 돌리는 실행 단위 ("직원 여러 명").

## 3. 도구
- **Wireshark**: 네트워크 패킷을 낚아채 내용을 들여다보는 분석 도구 (도청기 겸 현미경).
- **필터(filter)**: 수많은 패킷 중 보고 싶은 것만 거르는 조건 (예: `tcp.port == 9999`).
- **Follow TCP Stream**: 한 연결에서 오간 데이터를 "대화 원문"으로 합쳐 보여주는 기능.
- **loopback 인터페이스**: 내 컴퓨터가 자기 자신에게 보내는 통신(127.0.0.1)이 다니는 통로.
- **GNS3**: 가상 PC·스위치·라우터로 네트워크를 통째로 시뮬레이션하는 도구.
- **scapy**: 파이썬으로 패킷을 직접 만들고 보내고 분석하는 라이브러리 (공격·탐지에 사용).

## 4. 보안·공격
- **평문(plaintext)**: 암호화 안 된, 그대로 읽히는 데이터 ("벌거벗은 메시지").
- **암호문(ciphertext)**: 암호화되어 뒤섞인, 못 읽는 데이터 ("옷 입은 메시지").
- **암호화(encryption)**: 평문을 암호문으로 바꿔 아무나 못 읽게 만드는 것.
- **TLS**: 통신에 자물쇠를 채워 엿보기·변조를 막는 보안 규약 (https의 🔒).
- **무결성(integrity)**: 데이터가 중간에 변조되지 않았음을 보장하는 성질.
- **인증서(certificate)**: "이 서버가 진짜다"를 증명하는 신분증 (TLS가 상대 확인에 사용).
- **MITM(중간자 공격)**: 통신하는 둘 사이에 몰래 끼어들어 엿보거나 바꾸는 공격.
- **ARP Spoofing**: 같은 랜에서 "이 IP 주인은 나야"라고 거짓말해 남의 트래픽을 가로채는 수법.
- **ARP 탐지**: 같은 IP에 서로 다른 MAC이 보이면 "누가 속이는 중"이라고 알아채는 것.

## 5. 프로젝트 구조 (파일별 역할)
- **server.py**: 접속 받아 메시지를 모든 클라이언트에 중계하는 채팅 서버.
- **client.py**: 서버에 접속해 메시지를 보내고 받는 채팅 클라이언트.
- **mitm.py**: (3단계) ARP Spoofing으로 트래픽을 가로채고 탈취·변조하는 공격자 프로그램.
- **detector.py**: (4단계) ARP 트래픽을 감시해 공격을 탐지·경보하는 프로그램.
- **server_tls.py / client_tls.py**: (5단계) TLS 암호화를 적용한 채팅.
- **gen_cert.py**: 자체 서명 인증서를 만드는 헬퍼.

# 📎 실측 결과 — Docker 브리지(= GNS3 단일 스위치 동등) 실행 증거

> 환경: Docker 사용자 정의 브리지 `netlab`(172.30.0.0/24) = 모든 노드가 같은 L2(브로드캐스트 영역).
> GNS3의 "단일 스위치에 노드 4대" 토폴로지와 **네트워크적으로 동등**하다.
> 노드: 서버 .10 / 피해자 .11 / 공격자 .13 / 탐지기(피해자 호스트 기반).
> 공격자 컨테이너에는 패킷 조작 권한(NET_ADMIN·NET_RAW)과 IP 포워딩(ip_forward=1)을 부여.
> ※ MAC 주소는 컨테이너 실행마다 무작위라 시나리오별로 값이 다름(정상).

---

## 시나리오 ① 평문 TCP — MITM 공격 성공

피해자(.11)가 서버(.10)로 평문 메시지를 보내는 동안, 공격자가 ARP Spoofing으로 끼어든다.

**ARP 테이블 오염 (피해자 입장에서 서버 .10의 MAC)**
```
[공격 전] 172.30.0.10  →  3e:b5:bd:74:39:16   (진짜 서버 MAC)
[공격 후] 172.30.0.10  →  96:93:dc:2c:4e:35   (공격자 MAC으로 바뀜!)
```

**공격자가 가로챈 평문**
```
[탈취 172.30.0.11] 기밀#5 비밀번호 secret1234
[탈취 172.30.0.11] 기밀#6 비밀번호 secret1234
[탈취 172.30.0.11] 기밀#7 비밀번호 secret1234
```
→ 비밀번호가 **원문 그대로** 공격자 콘솔에 노출됨.

---

## 시나리오 ② ARP Spoofing 탐지 (방어 측)

탐지기를 피해자 호스트에서 구동(ARP 응답은 유니캐스트라 제3자 위치에서는 안 보이므로, 보호 대상 호스트에서 감시하는 것이 올바른 배치).

```
[탐지] ARP 응답 감시 시작.
[학습] 172.30.0.10 = da:ac:5a:52:c4:32      ← 정상 서버 MAC 학습
[학습] 172.30.0.11 = 8e:2a:f5:a8:1f:96
[경보] ARP Spoofing 의심! IP 172.30.0.10 의 MAC이 바뀜
       기존 da:ac:5a:52:c4:32  ->  신규 b6:1f:3c:95:03:58
```
→ 같은 IP(.10)에 다른 MAC이 나타나는 순간 **경보**. (수업 2.3절 탐지 원리 그대로)

---

## 시나리오 ③ TLS 적용 후 재공격 — 방어 성공

동일한 ARP Spoofing을 그대로 수행. 공격자는 여전히 트래픽을 가로채지만:

```
가로챈 라인 수       : 24 줄 (탈취 자체는 성공)
평문 'secret1234'   : 미검출 ✅
가로챈 내용(예)      : [탈취 172.30.0.11]  1\xTPe...<복호화 불가한 암호문>...
```
→ **같은 공격인데** 내용이 전부 암호문이라 읽히지 않음. 암호화 유무가 결과를 가른다.

---

## 종합 비교

| 항목 | 평문 TCP | TLS |
|---|---|---|
| ARP 오염 | 성공 | 성공(공격은 성립) |
| 메시지 탈취(가로채기) | 가능 | 가능 |
| **내용 읽기** | **가능(secret1234 노출)** | **불가(암호문)** |
| 탐지 | detector 경보 | detector 경보 |

## 재현 명령 (요약)

```bash
# 브리지 생성
docker network create --subnet 172.30.0.0/24 netlab
# 서버
docker run -d --name srv --network netlab --ip 172.30.0.10 th0oel/cbnu-netlab:v2 python server.py
# 피해자(평문 전송)  /  TLS 비교 시 server_tls.py + 클라이언트 TLS 접속
docker run -d --name victim --network netlab --ip 172.30.0.11 th0oel/cbnu-netlab:v2 python client.py   # 또는 전송 스크립트
# 공격자(ARP Spoofing + 탈취)
printf 'LAB\n' | docker run -i --rm --name attacker --network netlab --ip 172.30.0.13 \
  --cap-add NET_ADMIN --cap-add NET_RAW --sysctl net.ipv4.ip_forward=1 \
  th0oel/cbnu-netlab:v2 python mitm.py --victim 172.30.0.11 --gateway 172.30.0.10
# 탐지기(피해자 호스트 기반)
docker run --rm --network container:victim --cap-add NET_RAW th0oel/cbnu-netlab:v2 python detector.py
```
